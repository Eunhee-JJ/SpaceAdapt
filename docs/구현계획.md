### 4.1 지연 시 절삭 순서

1. 실행 가이드 → 텍스트 목록만
2. 사진 업로드 → 합성 방의 정답 단서로 질문 시연
3. 활동 영역 오버레이 → 점수 수치만 표시
4. 편집기 크기 수정 → 드래그·회전만
